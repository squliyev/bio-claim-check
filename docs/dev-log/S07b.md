# S07b — Sieve v2, pre-registration, frozen and sealed dataset

**Goal:** the evaluation dataset exists in git, frozen and sealed, before any prompt or rule-pack tuning.
The rules that pick candidates were committed and tagged before the first fetch.

## Built

- **Sieve v2** (`features/corpus/eligibility.py`, ADR 0011): the `protocol` never-reason, the
  baseline-balance skip in the null rule, the fifth kind `background_as_result` (rule `prior_finding`),
  and case-sensitive numeric `HR`/`OR`/`RR`.
- **Own-split pools and response hashes** (`app/usecases/build_corpus.py`): `questions.jsonl` records
  `pool_size`, `split_pool_size` and the sha256 of the raw response for each exact query.
- **Seal and verify** (`features/corpus/seal.py`, pure): `dataset_problems` lists every reason the
  dataset is not intact; `corpus seal` and `corpus verify` CLI commands; arch tests on the real
  `datasets/`, including the guard that no tracked file outside `datasets/` names a test id.
- **Audit tooling, dev only** (`features/corpus/audit_sheet.py`, `app/usecases/corpus_audit.py`): public
  order, exact-first-N parsing, seal-stamped no-clobber records. No test export until the S12 freeze.
- **Wilson interval** (`features/bench/stats.py`), checked against reference values.
- **Data:** `datasets/` (spec, questions, dev and test sources, manifest, `SEALED`, README).
- **Docs:** ADR 0011 (extends 0010, with a pointer in 0010), `docs/data-card.md`, `datasets/README.md`,
  the root README licence paragraph, invariants I41–I42, glossary terms, backlog B2 ✅ and B2b reworded.
