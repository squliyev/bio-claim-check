# S08b — Retrofit: canonical JSON, typed errors, redacted logging, unreported reasoning

**Goal:** redo four things S01–S08 already handled, in a better shape, before S09 adds provider adapters on
top of them. No new product behaviour: every output byte, hash, golden, cache key, seal and exit code stays
the same.

## Built

- **`common/canonical_json.py`:** `compact_json`, `pretty_json`, `pretty_json_bytes`, `sha256_of_compact`.
  The five inline `json.dumps` copies (corpus serialisation, report bytes, cache key, prompt hash, schema
  script) now use it. `allow_nan=False` everywhere. Ruff `TID251` bans `json.dumps`/`json.dump` elsewhere,
  with a per-file ignore for this module only.
- **`common/errors.py`:** `BccError` with a stable dotted `code`. 19 error classes re-parented, each keeping
  its stdlib base so every existing `except` still matches. `docs/error-codes.md` lists every code and the
  CLI exit codes; README links to it.
- **`app/cli`:** `ExitCode` (`IntEnum`, same values 2–7); no bare integer exits remain. Logging is
  configured right after settings load in `_settings()`, so commands that need no settings (`run --fake`,
  `--version`) stay setup-free.
- **`app/logging_setup.py`:** stdlib logging only (no new dependency). One stderr handler on the package
  logger, `propagate=False`, JSON lines (or `text`), no timestamps. Secret-keyed `extra` fields are redacted
  recursively on a copy; the record is never mutated; exceptions log their type only. `log_level` defaults
  to WARNING, new `log_format` setting.
- **`engine/llm/usage.py`:** `reasoning_tokens: int | None` (None = not reported). A sum with an unreported
  side is `None`; cost is unchanged. `Usage.zero()` replaces positional construction.
- **Tests:** `tests/support/settings.py::make_settings` (via `model_validate`, no env file);
  `test_canonical_json`, `test_logging_setup`, `test_error_codes` (each checker has proof tests on fakes),
  usage cases; a global fixture restores the package logger between tests.
- **Docs:** ADR 0013, invariants I48–I51, backlog A9, `docs/architecture/rings.dot` regenerated.

## Byte-identity evidence

- Manifest of every tracked file under `datasets/` and every golden under `tests/` (sha256), taken before the
  refactor and re-taken after: **identical** (`docs/architecture` excluded; it changes because `common`
  gained modules).
- A probe printing cache keys, prompt hashes, report bytes and corpus bytes: **identical** before and after.
- `corpus verify` passes; the seal `fd519195…` is unchanged.

## Accepted wire change

`reasoning_tokens` now serialises as `null` when a provider does not report it, instead of `0`. No committed
artifact contains a usage record yet (cache contents are git-ignored), so nothing tracked changed.

**Stderr format (diagnostics, not artifacts).** Before S08b, unconfigured stdlib logging printed bare messages
such as `europepmc: HTTP 503, retrying`. Those same warnings are now one JSON object per line (or
`LEVEL logger: message` with `BCC_LOG_FORMAT=text`). `BCC_LOG_LEVEL` was read but never applied before; it now
takes effect, so an old `.env` copied from the previous `.env.example` (`BCC_LOG_LEVEL=INFO`) prints INFO
lines. `bio-claim-check config` lists the new `log_format` setting. Stdout, artifacts, hashes, goldens and
the seal are unchanged.

## Decisions

- `__init_subclass__` enforcement of `code` was dropped: the no-registry guard forbids class-creation hooks
  in core. The same checks (missing, malformed, inherited, duplicate code) run in `tests/arch/test_error_codes.py`
  over the package, found with `import_package`.
- I48 is scoped to canonical artifacts and hash inputs. `model_dump_json` for cache storage and the `config`
  print are out of scope (they are not hashed or compared).
- Exceptions are not mapped to exits centrally yet; per-command `except` blocks keep their messages (→ S16).
