# S12c — Prompt overfitting audit and freeze v2

**Goal:** before the maintainer's test audit uses the freeze, make sure no prompt or rule text is fitted to
particular papers or questions (ADR 0021).

## Audit (read-only)

| Check | Result |
|---|---|
| Verify prompt v1: does it name a drug, a disease, a PMID or paper wording? | None; never tuned |
| Answer prompts (strict v1, over-eager v2) | Generic wording only |
| `src` special-casing of drugs, diseases or PMIDs | None |
| Challenge claims compared with the few-shot examples | Not copies (max token-set similarity 64) |
| Rule-pack few-shot topics compared with the questions | **3 of 9 scenarios overlapped** (Alzheimer's mouse model, colorectal registry cohort, type 2 diabetes) |

For comparison, we read how Claude Code's classifier prompts are built: they state the stakes, give each
class a definition and a test, set hard boundaries between neighbouring classes, and use generic worked
examples. Our verify prompt already follows the core of this. We did not restructure it: there was no
failure to fix, and the challenge set had one run left.

## Built

- **The 6 overlapping examples were re-topic'd, not removed.** All 18 examples, the 9 rules and their
  lessons stay. Rule pack `0.2.0`.
  - The first replacements (bone, fractures, psoriasis, HIV, plaque, women) were rejected: those words
    appear in source MeSH metadata or in a test question.
  - The final topics (gout in rabbits, an asthma registry, atopic dermatitis in teenagers) appear in no
    question, query or source metadata of either split.
  - The maintainer confirmed the wording before the run.
- **`tests/arch/test_prompt_neutrality.py` (I75).** It takes the query terms of every question. The
  generic vocabulary the rules need is listed with reasons. It fails on the old pack.
- **Results moved to `challenge/results/<freeze>.json`** (v1's bytes unchanged). `challenge run --record
  --name`, `freeze write --name` and the test gate all use `ACTIVE_FREEZE`.
- **Freeze v2** is pinned and active. The characterisation run ids changed with the rule-pack hash.

## Limits

- The guard matches exact query terms only; synonyms pass it.
- Generic vocabulary (cohort, mice, survival, …) is still shared with the questions, by necessity.
- The ZT-88 (fasting glucose) and QL-12 (survival) examples were kept: their overlap is generic, as the
  maintainer chose.
