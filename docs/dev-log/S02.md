# S02 — Architecture guardrails and project documents

- **Date:** 2026-10-20
- **Outcome:** every architecture rule is enforced by a real tool, and a test proves each one fires.

## Built

- Package boundaries for every ring and feature slice. Each module has a `[RING:…]` docstring stating
  what it does and what it must not do.
- Four import-linter contracts with ids: `rings`, `slices`, `no-llm-in-deterministic-code`,
  `contracts-do-not-depend-on-slices`.
- A rule-fire harness (`tests/support/fixture_pkg.py`). It reads the real contracts from
  `pyproject.toml`, re-roots them onto a generated package, plants one import, and runs each contract
  in isolation. Rogue cases must break with the exact edge in the output. Allowed cases must pass.
  Configuration errors are reported as errors, never as a pass.
- A ruff `TID251` ban on importing `tests` from production code, with tests that the ban fires.
- Residual guards: ring headers, the `[TEST SUPPORT]` header, and the ADR header fields.
- Parity tests: ADR index ↔ files; invariant references resolve; CITATION smoke; issue form; the wheel
  ships LICENSE.
- Documents: ADRs 0001–0004 with an index and template, `docs/invariants.md`, `docs/backlog.md`,
  AGENTS.md, the README architecture figure, LICENSE (Apache-2.0), CITATION.cff, CONTRIBUTING,
  CODE_OF_CONDUCT and SECURITY.

## Decisions

- import-linter is pinned to `2.15.*`. The harness depends on its output format.
- The build backend is pinned exactly (`hatchling==1.32.4`) because it sits outside `uv.lock`.
- ADR 0005 (cache/replay contract) moved to S08, when the cache exists.
- Dependabot ignores Python minor/major bumps. 3.13 is a project decision, not drift.
